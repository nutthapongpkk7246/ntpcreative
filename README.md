# NTP Creative Studio

Static production website for NTP Creative Studio.

## Production
- Site: https://ntpcreative.vercel.app/
- GA4 Measurement ID: G-1NJCNXW7HT

## Analytics events
- `contact_click` — LINE / Messenger / Facebook / TikTok clicks, including placement and quote context when available
- `quote_brief_copy` — quick-quote brief copied
- `portfolio_filter` — portfolio category selected
- `portfolio_item_view` — portfolio item opened
- `package_select` — package selected

## Deploy
Import this repository into the existing Vercel project `ntpcreative` and deploy as a static project. No serverless functions are required.
